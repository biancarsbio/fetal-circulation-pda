# fetal-circulation-pda

Interactive teaching diagrams of fetal and newborn circulation and patent ductus arteriosus (PDA).

- **Shunts at birth**: the foramen ovale and ductus arteriosus, from the fetus to an infant with a PDA
- **The full circuit**: heart, lungs and great arteries in the fetus, a normal newborn, and an infant with a PDA

Live page: https://biancarsbio.github.io/fetal-circulation-pda/
